## Yapılacak iş ve çıktılar

1. KUKA current→A→B deterministik demo: duration, timestep, örnek sayısı, dq/ddq maxima, limit ihlali, A/B pose hata, solver/interpolator.
2. q/dq/ddq–zaman, TCP XYZ ve 3B path grafikleri; ham trajectory ve config hashleri.
3. F0/Core/H2/MR ilgili regresyonları, TR bütün testleri; MP için waypoint zamanlama API ve limit profili devri.
